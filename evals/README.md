# KIW1 20-Task Proof of Self-Improvement Benchmark

## Overview

This benchmark measures the measurable delta in agent performance before and after a learning session.

### The Ground Rule

**Cold and learned runs execute the exact same prompts through the exact same agent orchestrator entry point (`orchestrator.run_turn()`) and are evaluated by the exact same machine-checkable assertions.**

The only difference between the two runs is what exists in the durable store (Cloud Firestore or local store):
- **Memory Palace**: spatial facts (`room -> locus -> item`)
- **Correction Ledger**: learned situation-rule constraints
- **Skill Registry**: forged and registered capabilities

---

## Scoring Method & Assertion Types

All 20 tasks in `benchmark_tasks.json` define deterministic, machine-checkable assertions:

| Assertion Type | Evaluation | Example |
|---|---|---|
| `output_contains` | Substring match in the model's generated text | `"Falcon"`, `"Auckland"`, `"602.5"` |
| `response_type` | Agent response type classification | `"clarification_needed"`, `"response"`, `"skill_list"` |
| `tool_used` | Specific tool executed during turn | `"web_search"`, `"query_vault"`, `"execute_skill"` |
| `learned_rule_applied` | Relevant rule injected from Correction Ledger | `"GST breakdown"`, `"ISO"` |
| `has_learned_rules` | Context-matched rules retrieved into prompt brief | Active ledger rule count $> 0$ |
| `plan_candidates_count` | Number of paths generated by Strategic Planner | 3 candidates scored |

### Deterministic vs Judged Split

- **Deterministic Machine-Checkable Tasks**: 20 / 20 (100%)
- **LLM-as-a-Judge / Subjective Tasks**: 0 / 20 (0%)

---

## Reproducing the Benchmark

To execute the full benchmark run (Cold Run $\rightarrow$ Learning Session $\rightarrow$ Learned Run):

```bash
python -m evals.runner
```

Output is written to `evals/results.json` and mirrored to `app/static/results.json` for live display in the web dashboard.

---

## Statistical Caveat

> [!NOTE]
> 20 tasks with a single evaluation pass is a compact benchmark suite designed for fast, reproducible verification during hackathon judging. In small sample sets of $N=20$, a variance of 1–2 tasks across runs can represent stochastic sampling noise rather than structural learning. The primary signal is the persistent category-level delta across memory recall, correction ledger injection, and forged skill reuse.
